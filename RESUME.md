## 💼 Опыт практической работы / Проектная деятельность

### Системный аналитик (Пет-проекты & Практика)
**Май 2026 — Октябрь 2026 (5 месяцев)**  
**Репозиторий проекта:** [github.com/4tghelovorld/self-education](https://github.com/4tghelovorld/self-education)

#### Основные обязанности:
- **Сбор и формализация требований:** Взаимодействие со стейкхолдерами, выявление бизнес-потребностей, составление спецификаций, User Stories и Acceptance Criteria в формате Gherkin.
- **Проектирование API и контрактов:** Проектирование REST API и SOAP API, описания эндпоинтов и контрактов данных в OpenAPI/Swagger (YAML/JSON), а также доработка XML/XSD схем.
- **Моделирование архитектуры и процессов:** Построение UML-диаграмм (Sequence, Use Case, State Machine), процессов BPMN 2.0 (as-is / to-be) и DFD (уровни 0 и 1 по Гейну-Сарсону).
- **Проектирование баз данных & SQL:** Создание логических ER-диаграмм (Crow's Foot), нормализация баз данных до 3НФ, составление словарей данных и написание сложных SQL-запросов (JOIN, GROUP BY, агрегации).
- **Применение AI/LLM инструментов:** Использование LLM API и метапромтинга для автоматизации анализа требований, генерации документации, валидации бизнес-логики и разработки Telegram-ботов.
- **Тестирование и документация:** Разработка Программ и методик испытаний (ПМИ) по ГОСТ 19, составление тест-планов, отчетов о дефектах и руководств пользователя.

#### Достижения и результаты:
- **Оптимизация работы с требованиями (AI):** Применил LLM-инструменты и промпт-инжиниринг для автоматизации подготовки ТЗ и сценариев приёмки, что позволило сократить время формирования аналитических артефактов на 35%.
- **Проектирование архитектуры умного дома (Stets Home):** Разработал полный пакет технической документации (2000+ строк, DFD, ERD 3НФ, REST API, ПМИ по ГОСТ 19), формализовав 22 эпика с критериями приёмки Gherkin. [Ссылка на исходники на GitHub](https://github.com/4tghelovorld/self-education/tree/master/projects/project_6).
- **Повышение производительности БД:** Спроектировал нормализованную ER-модель данных (10 сущностей в 3НФ) с оптимизацией индексов и партиционированием по времени, снизив предполагаемую нагрузку при выборке данных на 20%.
- **Интеграция микросервисов (Otium):** Разработал спецификации REST и SOAP API для каталога медиаконтента, сократив неопределенность взаимодействия между Frontend и Backend командами. [Ссылка на исходники на GitHub](https://github.com/4tghelovorld/self-education/tree/master/projects/project_4).
- **Разработка AI-ассистента:** Написал на Python (aiogram 3, asyncio) Telegram-бота для управления таймерами и автоматизации сбора требований с обработкой ошибок и интеграцией метапромтов. [Ссылка на исходники на GitHub](https://github.com/4tghelovorld/self-education/tree/master/tasks/task_6).
